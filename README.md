# 알림함 — 여러 사이트(VAPID 키)의 웹 푸시 수신함

서버 없이 정적 파일만으로 동작하는 PWA입니다. 사이트마다 VAPID 공개키를 등록하면 알림이 사이트별로 분류되어 기기 안(IndexedDB)에 쌓입니다. 최대 10개.

## GitHub Pages로 배포
1. 새 저장소를 만들고 이 폴더의 파일을 전부 올립니다(`.nojekyll` 포함).
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
3. `https://<계정>.github.io/<저장소>/` 로 접속합니다. (비공개 저장소의 Pages는 유료 플랜이 필요합니다. 이 앱에는 비밀값이 없어 공개 저장소여도 안전합니다.)

## 폰에 설치
- Android(Chrome): 메뉴 → 앱 설치 / 홈 화면에 추가
- iOS 16.4+(Safari): 공유 → 홈 화면에 추가 → **홈 화면 아이콘으로 실행**한 뒤 사이트를 추가하세요.

## 사용
1. "사이트 관리"에서 이름과 VAPID 공개키를 넣고 추가합니다. 구독 정보(JSON)가 표시됩니다.
2. 그 JSON을 해당 사이트의 발송 쪽(DB 등)에 저장하고, 그 사이트의 개인키로 서명해 푸시를 보내게 합니다.
3. 페이로드는 `{"title","body","url"}` JSON을 권장합니다. 일반 텍스트면 본문으로 저장됩니다.

테스트 발송: `npm i web-push` 후 `tools/send.js` 참고. 개인키는 환경변수로만 사용하고, 저장소나 채팅에 올리지 마세요.

## 구조
브라우저는 서비스 워커 하나당 푸시 구독을 하나만 가질 수 있어서, 사이트마다 `slots/N/sw.js` 로 별도 서비스 워커를 등록합니다(N=슬롯 번호). 로직은 `sw-core.js` 하나에 있습니다.
